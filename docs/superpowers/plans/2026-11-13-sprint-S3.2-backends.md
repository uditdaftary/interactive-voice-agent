# Sprint S3.2: STT and TTS backends. Implementation plan

> **For agentic workers:** follow the orchestration protocol in `docs/superpowers/plans/2026-11-13-remediation-roadmap.md`. Steps use checkbox (`- [ ]`) syntax.

**Goal:** STT and TTS sit behind small backend protocols. Whisper output passes the speech judge. The Google STT fallback, the mock STT engine in production code and the synthetic-tone TTS tier are gone. pyttsx3 uses one engine and picks the right gender.

**Architecture:**
- `stt/backends.py` and `tts/backends.py` hold the protocols and the concrete backends.
- `stt/speech_judge.py` holds the judge moved out of the Moonshine worker, which imports it back.
- `recognizer.STTEngine` and `synthesizer.synthesize_sentence` stay as thin adapters with today's call signatures, so server code is untouched. S3.3 wires the backends in directly and deletes the adapters.

**Tech stack:** faster-whisper, edge-tts 7.3.1 (`boundary="WordBoundary"`), pyttsx3, numpy, scipy.

**Spec:** sections 5.5 (without Moonshine) and 5.6 (without Pocket). Matrix: M16, L9, L10, L12.

## Review focus
1. The judge must see the audio Whisper decoded *before* gain normalisation. Normalising first lifts a dead input above `QUIET_PEAK_DB` and defeats the "quiet" check.
2. A real spoken sentence must not be rejected. The slow benchmark clip (`models/voices/david-martinez.wav`) must still produce a non-empty transcript.
3. pyttsx3 is not thread-safe. Every engine call, including creation, happens on the one dedicated thread.
4. "female" contains "male". Both the voice-id check and the voice-name check match whole words.
5. When every TTS backend fails, `synthesize_sentence` returns `(None, "")`. `narration.py` already skips the send and still advances the cursor; don't change it.

- `@dataclass(frozen=True) class Transcript: text: str; rejected_reason: str | None = None`.

- `class WhisperBackend` with `__init__(self, model_size: str = "tiny.en", device: str = "cpu", compute_type: str = "int8", initial_prompt: str = "")`. It holds today's `STTEngine` logic (resample to 16 kHz, the peak gate, gain normalisation, the two-pass `vad_filter` decode) with these changes:

  - `transcribe(self, audio_data: bytes | bytearray | np.ndarray, sample_rate: int = 16000) -> str` returns `.text`. A float32 ndarray is converted to int16 bytes first, as today.

### Task 3: TTS backends (L9, L10)

**Files:**
- Create: `src/voice_agent/tts/backends.py`
- Modify: `src/voice_agent/tts/synthesizer.py`, `src/voice_agent/settings.py`
- Test: `tests/test_tts_backends.py`

**Interfaces:**
- `@dataclass(frozen=True) class SpeechAudio: data: bytes; mime: str; word_times: list[float] | None = None`. `mime` is `"audio/mpeg"` or `"audio/wav"`. `word_times` are word start times in seconds.
- `class TtsError(RuntimeError)`.
- `class TtsBackend(Protocol)`: `name: str`; `async def synthesize(self, text: str, voice_id: str, cadence: float) -> SpeechAudio` raises `TtsError` on failure or empty audio.
- `CHARACTER_AUDIO_PROFILES`, `CharacterAudioProfile` and `DEFAULT_EDGE_VOICE` move to `backends.py`.
- `class EdgeTtsBackend` (`name = "edge"`): today's rate and pitch arithmetic; `edge_tts.Communicate(..., boundary="WordBoundary")`; collect `chunk["offset"] / 1e7` from `WordBoundary` chunks into `word_times`. No audio raises `TtsError`.
- `class Pyttsx3Backend` (`name = "pyttsx3"`):
  - one `ThreadPoolExecutor(max_workers=1, thread_name_prefix="pyttsx3")` per instance; the engine is created lazily on that thread and reused (L9);
  - temp WAV deletion failure logs a WARNING with the path (L9);
  - `def pick_voice(voices: Sequence[Any], female: bool) -> str | None`, a module function, matches whole words: `re.search(r"\bfemale\b", ...)` versus `r"\bmale\b"`, plus the existing `zira`/`hazel`/`david` names (L10). The voice-id check uses `re.search(r"\bfemale\b|lucy", voice_id)`.
- `class ChainedTts`: `__init__(self, backends: Sequence[TtsBackend])`; `async def synthesize(self, text, voice_id, cadence) -> SpeechAudio | None`. It tries each backend in order. Each failure logs a WARNING naming the backend and `type(exc).__name__`. `status: str` becomes `"ok"`, `"fallback:<name>"` or `"unavailable"` after each call.
- `def build_tts(primary: str = "edge") -> ChainedTts`: the primary first, then the other of `edge`/`pyttsx3`. An unknown name raises `ValueError`.
- `Settings.tts_primary: str = "edge"`, env `VOICE_AGENT_TTS_PRIMARY`.
- `synthesizer.py` keeps only `synthesize_sentence(text, voice_id="david-martinez", cadence=1.0) -> tuple[bytes | None, str]`, marked `# removed in S3.3`. It uses a module-level `build_tts(load_settings().tts_primary)` created on first call, and returns `(audio.data, "mp3" | "wav")` or `(None, "")`. `generate_synthetic_pcm_fallback` and the old `synthesize_speech_*` functions are deleted.
