# Sprint S0.2: test isolation, injection seams and the CI test job. Implementation plan

> **For agentic workers:** follow the orchestration protocol in `docs/superpowers/plans/2026-11-13-remediation-roadmap.md`. Steps use checkbox (`- [ ]`) syntax.

**Goal:** The default test suite never touches the network, finishes in under 30 s, and runs in CI. Production code gains the injection seams that later sprints test through. No user-visible behaviour change.

**Architecture:**
- `voice_agent/settings.py` holds every timing knob and endpoint default in one place.
- `NarrationEngine` and `create_app` accept injected collaborators (settings, LLM, TTS, search, STT) and default to the real ones.
- A conftest socket guard makes any outbound network call a test failure.

**Tech stack:** Python 3.11, pytest, pytest-asyncio, FastAPI TestClient.

**Spec:** `docs/superpowers/specs/2026-11-12-remediation-design.md`, section 6, matrix rows M2, M19, M20, M21, L15.

## Global constraints
- Branch `sprint/s0.2-isolation`, worktree `C:/Projects/iva-wt/S0.2`, base `origin/main` (S0.1 merged).
- Default values must equal today's hardcoded values, so behaviour does not change. Changing a value is a later sprint's job.
- Don't redesign `NarrationEngine` logic (S2.1 and S2.2 do that). Only replace literals with settings, and module-level calls with injected callables.
- Default suite target: under 30 s wall time on the orchestrator's Windows machine, and zero non-loopback connections.

## Review focus
1. A test that legitimately uses loopback (TestClient, a local fake HTTP server) must not be blocked by the socket guard. Allow `127.0.0.1`, `::1` and `localhost`.
2. `import voice_agent.server.app` (module-level `app = create_app()`) must not construct `STTEngine` or import `faster_whisper`.
3. Lazy STT creation must happen once even when two utterances arrive together: guard with an `asyncio.Lock`.
4. On Linux CI, pyttsx3 has no SAPI. Tests that exercise pyttsx3 for real carry the `windows` marker and skip elsewhere.
5. Each test that gets a fake injected must still assert behaviour, not just "did not crash".
